# Asset dùng chung

Đặt logo, ảnh nền, minh họa hoặc asset tĩnh được nhiều trang dùng tại đây.

Quy tắc chung cho việc tạo, bổ sung, kiểm tra và quản lý asset nằm trong [`docs/ASSETS.md`](../../../docs/ASSETS.md).

- Dùng tên file chữ thường, không dấu, có gạch ngang và mô tả rõ mục đích.
- Ưu tiên SVG cho hình vector và WebP/AVIF cho ảnh raster khi phù hợp.
- Ghi nguồn và giấy phép trong mô tả commit hoặc file `ASSET_CREDITS.md` ở gốc repo nếu dùng asset bên ngoài.
- Không lưu token, dữ liệu người dùng, file thiết kế gốc nặng hoặc nội dung chưa có quyền sử dụng.
